Open LDC

Mac. Under Apple menu → About This Mac, check whether your Mac has an Apple chip or an Intel processor. Unzip the matching download and move LDC to Applications. If macOS blocks the locally signed app, use System Settings → Privacy & Security → Open Anyway.

Windows. Extract the ZIP and open LDC.exe in the LDC folder. Keep the other files in the same folder. If SmartScreen blocks the unsigned app, choose More info → Run anyway.
