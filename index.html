DeepBioCounter

Mark, count, and measure objects in microscopy images. Select a region, add or edit marks, and export your results. The included model detects adipocytes in bone marrow H&E images. All image processing runs on your computer.

Open DeepBioCounter

Mac. Under Apple menu → About This Mac, check whether your Mac has an Apple chip or an Intel processor. Unzip the matching download and move DeepBioCounter to Applications. If macOS blocks the locally signed app, use System Settings → Privacy & Security → Open Anyway.

Windows. Extract the ZIP and open DeepBioCounter.exe. Keep the other files in the same folder. If SmartScreen blocks the unsigned app, choose More info → Run anyway.
